### `/png/` — Pre-rendered PNGs
All key variants at standard sizes:
- **Icons:** 64, 128, 256, 512px
- **Wordmarks:** 256, 512, 1024, 2048px
- **Favicons:** 16, 32, 48, 64, 180 (Apple Touch), 192, 512px

## Usage Guidelines

- **Light backgrounds** → use navy variants
- **Dark backgrounds** → use white variants
- **Minimum size** → U mark: 24px, wordmark: 80px wide
- **Clear space** → maintain padding equal to the U mark's diagonal cut width
- **Don't** stretch, rotate, recolor, or add effects
